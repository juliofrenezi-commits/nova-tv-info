Projeto pessoal

Nova TV

Uma central pessoal de entretenimento para Android TV, criada para organizar atalhos de streaming e facilitar a navegação com o controle remoto.

Sobre o aplicativo

O Nova TV é desenvolvido para uso doméstico e sem fins comerciais. O projeto reúne atalhos para aplicativos de streaming e está sendo preparado para apresentar informações de filmes e séries usando a API do TMDB.

O aplicativo não vende conteúdo, não oferece assinaturas e não hospeda nem transmite filmes ou séries. Cada serviço de streaming é acessado por meio do aplicativo oficial correspondente, conforme a disponibilidade e a assinatura do usuário.

Créditos

Quando os dados do TMDB estiverem integrados, o aplicativo exibirá a atribuição exigida: “This product uses the TMDB API but is not endorsed or certified by TMDB.” O TMDB e seus dados pertencem aos respectivos titulares.
